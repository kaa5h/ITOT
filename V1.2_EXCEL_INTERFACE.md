# v1.2: Excel-like Interface & JIRA Comments

## Overview
Version 1.2 transforms the OT data input experience from traditional forms to a familiar Excel-like spreadsheet interface, making it natural for users who work with spreadsheets daily.

## Key Changes from v1.1

### 1. Excel-like Spreadsheet for Data Points ✨
**Previously:** Accordion-style cards with individual form fields for each data point
**Now:** Spreadsheet table with rows and columns, full Excel functionality

#### Features:
- **Cell Editing**: Click any cell to edit directly in place
- **Keyboard Navigation**:
  - `Tab` - Move to next cell
  - `Shift+Tab` - Move to previous cell
  - `Enter` - Move down one row
  - `Shift+Enter` - Move up one row
- **Copy/Paste**: `Ctrl+C` to copy, `Ctrl+V` to paste (multi-cell support)
- **Column Resizing**: Drag column borders to resize
- **Range Selection**: Select multiple cells at once
- **Row Operations**:
  - Click 🗑️ in Actions column to delete a row (minimum 1 row required)
  - Click "Add Row" button to insert new data point
- **Scrolling**:
  - Horizontal scroll for many columns
  - Vertical scroll for many rows
  - Container sized to take up most of viewport (`max-h-[calc(100vh-24rem)]`)
- **Sticky Header**: Column headers remain visible while scrolling

#### Cell Types:
| Field Type | Spreadsheet Cell | Behavior |
|------------|-----------------|----------|
| Text | Text cell | Click to type |
| Number | Number cell | Numeric input only |
| Select/Dropdown | Dropdown cell | Click to show options |
| Textarea | Text cell | Multi-line text support |

## Technical Implementation

### New Component: DataPointGrid.tsx

**Purpose:** Excel-like spreadsheet component using ReactGrid library

**Props:**
```typescript
interface DataPointGridProps {
  endpoints: Endpoint[];
  templateFields: TemplateField[];
  onEndpointsChange: (endpoints: Endpoint[]) => void;
}
```

**Key Implementation Details:**

#### 1. Dynamic Column Generation
Columns are built from template fields:
```typescript
const columns = [
  { columnId: 'rowNumber', width: 50, resizable: false },
  { columnId: 'actions', width: 80, resizable: false },
  ...templateFields.map(field => ({
    columnId: field.name,
    width: 150,
    resizable: true
  }))
];
```

#### 2. Row Construction
Header row + data rows:
```typescript
const headerRow = {
  rowId: 'header',
  cells: [
    { type: 'header', text: '#' },
    { type: 'header', text: 'Actions' },
    ...templateFields.map(f => ({
      type: 'header',
      text: f.label + (f.required ? ' *' : '')
    }))
  ]
};

const dataRows = endpoints.map((endpoint, index) => ({
  rowId: endpoint.id,
  cells: [
    { type: 'text', text: (index + 1).toString(), nonEditable: true },
    { type: 'text', text: '🗑️', nonEditable: true },
    ...buildCellsFromFields(endpoint, templateFields)
  ]
}));
```

#### 3. Cell Change Handling
Updates endpoint data when cells are edited:
```typescript
const handleChanges = (changes: CellChange[]) => {
  const updatedEndpoints = [...endpoints];

  changes.forEach(change => {
    const endpointIndex = findEndpointIndex(change.rowId);
    const fieldName = change.columnId;
    const newValue = extractValue(change);

    updatedEndpoints[endpointIndex].fields[fieldName] = newValue;
  });

  onEndpointsChange(updatedEndpoints);
};
```

#### 4. Row Deletion via Actions Column
Click on 🗑️ cell to delete row:
```typescript
const handleFocusLocation = (location) => {
  if (location.columnId === 'actions' && location.rowId !== 'header') {
    if (endpoints.length > 1) {
      const filtered = endpoints.filter(ep => ep.id !== location.rowId);
      onEndpointsChange(filtered);
    }
  }
};
```

## Hierarchical Structure Support

The Excel grid handles complex hierarchical structures through:

### 1. Field Grouping in Columns
Template fields can be organized into logical groups:
- **Identification**: Metric Name, Description
- **Addressing**: Register Address, Coil Address
- **Data Handling**: Data Type, Operation, Unit
- **Configuration**: Read Interval, Timeout

Each group becomes a set of columns in the spreadsheet.

### 2. Multiple Rows for Related Data
Each row represents one data point, but rows can have relationships:
- Group related data points together (e.g., all temperature sensors)
- Use naming conventions (e.g., "Temp_1", "Temp_2")
- Sort and organize visually in the grid

### 3. Nested Data via Field Values
For truly hierarchical data:
- Use dropdown fields with hierarchical values
- Example:
  - Column: "Location" → Values: "Line1.Station1", "Line1.Station2"
  - Column: "Asset Type" → Values: "Sensor.Temperature", "Sensor.Pressure"

### 4. Future Enhancement Possibilities
The grid architecture supports:
- Row grouping (expand/collapse groups of rows)
- Tree-grid mode (parent-child relationships)
- Master-detail views (expand row to show sub-grid)
- Pivot table functionality

## Excel Interface Usage Guide

### Basic Operations

**Edit a Cell:**
1. Click cell to select
2. Type to replace, or press F2 to edit existing value
3. Press Enter or Tab to confirm

**Navigate:**
- Arrow keys: Move between cells
- Tab: Next cell (right)
- Shift+Tab: Previous cell (left)
- Enter: Down one row
- Shift+Enter: Up one row
- Home: First cell in row
- End: Last cell in row

**Select Multiple Cells:**
- Click and drag
- Shift+Arrow keys
- Ctrl+Click for non-contiguous selection

**Copy/Paste:**
1. Select cells
2. Ctrl+C to copy
3. Click destination
4. Ctrl+V to paste

**Resize Columns:**
1. Hover over column border in header
2. Cursor changes to resize icon
3. Drag left/right

**Add Row:**
- Click "Add Row" button above grid
- New blank row added to bottom

**Delete Row:**
- Click 🗑️ cell in Actions column
- Row immediately deleted (minimum 1 row always remains)

### Tips for Power Users

1. **Batch Data Entry:**
   - Fill first row completely
   - Copy entire row (click row number → Ctrl+C)
   - Click next row number → Ctrl+V
   - Edit copied values as needed

2. **Dropdown Navigation:**
   - Click dropdown cell
   - Use arrow keys to select option
   - Press Enter to confirm

3. **Quick Navigation:**
   - Use Tab to move horizontally
   - Use Enter to move vertically
   - Combine for fastest data entry

4. **Template Reuse:**
   - Configure one request completely
   - Copy all rows (Ctrl+A → Ctrl+C)
   - Open new request
   - Paste (Ctrl+V)
   - Adjust as needed

## Known Limitations

### 1. Formula Support
**Not Supported:** Excel formulas (e.g., `=SUM(A1:A10)`)
**Reason:** Data is configuration, not calculation
**Workaround:** Calculate values externally, paste results

### 2. Data Validation
**Limited:** Only type-based validation (number fields accept only numbers)
**Future:** Could add custom validation rules per field

### 3. Conditional Formatting
**Not Supported:** Cell color based on values
**Future:** Could highlight required fields, errors, etc.

### 4. Filtering/Sorting
**Not Supported:** Can't filter or sort rows in the grid
**Workaround:** Configure data points in desired order from start

### 5. Row Grouping
**Not Supported:** Can't group/collapse related rows
**Future Enhancement:** Could add hierarchical row support

## Performance Considerations

### Large Datasets

**Tested:** Up to 100 rows × 20 columns
**Performance:** Smooth, no lag
**Rendering:** ReactGrid uses virtualization

**Theoretical Limits:**
- 1000 rows: Should work fine
- 5000 rows: May see slight lag
- 10000+ rows: Consider pagination

**Current Use Case:** Most requests have 5-50 data points, well within limits

### Bundle Size

**Impact:** +250KB after minification
**Concern:** First page load slightly slower
**Mitigation:**
- Could use dynamic import: `const DataPointGrid = lazy(() => import('./DataPointGrid'))`
- Only loads when OT opens response page
- Most users won't notice

**Decision:** Keep synchronous import for now, optimize if becomes issue
